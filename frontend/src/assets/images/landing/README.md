# 랜딩 일러스트

H01 비회원 홈의 일러스트. 모두 ChatGPT로 제작(사용자 제작·전달, 2026-11-06)한 투명 배경(알파 채널) PNG 원본과, 그 원본에서 만든 표시용 WebP의 쌍이다. Claude Code가 생성한 이미지가 아니다.

| 이름                                      | 원본 PNG               | 표시용 WebP       | 사용 위치                                                      |
| ----------------------------------------- | ---------------------- | ----------------- | -------------------------------------------------------------- |
| `mealthroutine-landing-hero-illustration` | 1536×1024, 1,512,867 B | 576×457, 49,894 B | `landingImages.ts` hero 슬롯 → "기록 방법" 섹션 머리           |
| `mealthroutine-landing-quiz-illustration` | 1536×1024, 1,514,634 B | 720×455, 84,710 B | quiz 슬롯 → 퀴즈 소개 배너                                     |
| `mealthroutine-landing-ai-illustration`   | 1536×1024, 1,329,756 B | 336×158, 21,350 B | 현재 미사용(ai 슬롯 비움: 제공 예정 기능의 비중을 낮추기 위해) |

WebP 폭은 최대 표시 폭의 3배다(hero 192px → 576px, quiz 240px → 720px). 미사용인 ai는 이전 규격(폭 336px)을 유지한다. 장식이라 `alt=""`로 쓴다.

## 변환

- 원본에서 알파 8%(20/255) 초과 영역에 사방 24px 여유를 둔 범위만 잘라 축소했다. 그림은 바꾸지 않았다. 잘린 경계의 알파 최댓값은 2/255 이하라 경계선이 보이지 않는다.
- Microsoft Edge 156.0.4314.58(Chromium) 캔버스의 고품질 보간 후 `canvas.toBlob('image/webp', 품질)`. 품질은 hero·quiz 0.85, ai 0.9다. 별도 변환 도구를 설치하지 않았다. 알파를 보존한다. 변환일 2026-11-06.
- hero·quiz는 H01 개편에서 표시 폭이 커져 원본 PNG에서 다시 변환했다(이전 폭 336px은 고밀도 화면에서 확대 표시됨).
- C2PA 메타데이터는 원본 PNG에만 있다. 출처 증빙이 필요하면 원본을 사용한다. 원본 PNG는 번들에 포함되지 않는다.

## 참고

- 전달 파일명 `a_clean_high_resolution_3d_cgi_illustration_on_a.png`, `AI 건강 분석 아이콘.png`은 위 이름으로 바꿨다(내용·해시 불변).
- 알파: 완전 투명 + 반투명(부드러운 그림자·빛). 미리보기 도구가 투명을 검정으로 보여 후광처럼 보이는 것은 착시이며, 실제 배경 위에서는 광채나 경계선이 보이지 않는다.
- 퀴즈 이미지는 1:1을 요청했으나 3:2로 전달되었다. 투명 여백을 잘라 쓰므로 그림에는 영향이 없다.

## 변경 규칙

- WebP를 수정하거나 교체할 때는 원본 PNG에서 다시 변환한다. WebP를 다시 인코딩하지 않는다.
- 원본 PNG는 삭제·덮어쓰기하지 않는다. 일러스트의 디자인과 색감은 변경하지 않는다.
